# 그림 (Images)

- 문서에 넣는 그림은 이 폴더에 둡니다.
- 파일 이름은 `<문서 이름>-<내용>.png` 형식으로 합니다. 예: `0003-data-flow.png`
- 문서에서는 상대 경로로 넣습니다. 예: `![데이터 흐름](../images/0003-data-flow.png)`
- 그림을 다시 그릴 수 있게 원본(draw.io 파일 등)이 있으면 함께 둡니다.
- 간단한 흐름도는 Mermaid처럼 문서 안에 글로 쓰는 다이어그램을 먼저 고려합니다. 수정하기 쉽고 변경 내역도 남습니다.
- 이슈 트래커나 메신저에 올린 그림의 링크는 시간이 지나면 끊기거나 권한 때문에 안 보일 수 있습니다. 문서에는 파일로 저장해서 넣습니다.

## 예시

`docs/README.md`처럼 `docs/` 바로 아래 문서에서는 이렇게 넣습니다.

```markdown
![문서의 세 종류 — 가이드는 지금 어떻게, how-to는 무엇을 하나, 결정 기록은 왜](images/example-doc-types.png)
```

결과:

![문서의 세 종류 — 가이드는 지금 어떻게, how-to는 무엇을 하나, 결정 기록은 왜](example-doc-types.png)

> `example-doc-types.png`는 형식을 보여 주는 예시입니다. 실제 그림은 위 파일 이름 규칙을 따릅니다.
